Can a blog post be handwritten?
Suppose I handwrite a post on my
supernote, then export it as a
webp, which supports XMP
metadata. Pretty sure I should be
able to read that with javascript.
Then, I could embed the webp on
a blog post, and write a script
that will toggle between hand-
writing and the OCR'd (and edited)
text metadata.
Worth an experiment, I reckon.
Wonder if you can read my
handwriting, though.
